# 倪海厦紫微斗数体系 1-8 落地蓝图

## 1. 来源登记系统

建立 source registry。每条资料先登记，不直接入库。字段包括 URL、标题、平台、媒介类型、权利状态、采集策略、人工复核状态、风险等级。

## 2. 多模态处理管线

文本、PDF、网页、视频、音频统一走同一条 metadata-first 管线。音视频只有在授权后才转写；未授权视频只登记 URL、标题、时间戳候选和人工复核状态。

## 3. 知识图谱

把资料拆成四类对象：

- `Rule`：可计算规则，如大限四化、流月五虎遁。
- `Interpretation`：星曜、宫位、四化、三方四正解读。
- `Pattern`：格局清单和触发条件。
- `Case`：命例、断语、验证结果。

每个对象必须绑定证据片段或内部硬约束。

## 4. 确定性排盘与规则引擎

紫微排盘、四化、大限、流年、流月、格局、自化、来因宫全部由确定性代码计算。AI 不负责算规则，只负责组织表达。

## 5. 证据型产品呈现

前端报告每条结论都带“依据”按钮，展开后展示：

- 算法路径
- 触发宫位
- 触发星曜
- 四化层级
- 来源证据
- 时间戳或页码
- 置信度
- 是否存在争议

## 6. 疾厄模块边界

疾厄、子午流注、经络、脏腑只作为传统命理/中医文化映射，不替代医疗诊断。产品文案必须避免确定性疾病诊断。

## 7. 四道质量闸

- 资料闸：来源和授权。
- 规则闸：是否符合倪师体系硬约束。
- 生成闸：输出是否超出证据范围。
- 审计闸：样本、来源、证据、文案全量检查。

## 8. 训练/RAG 阶段

只有 `authorized_fulltext`、`public_domain`、`user_private_authorized` 的资料能进入 RAG 或训练候选集。`metadata_only` 来源不得用于训练，只能做检索入口和人工核验线索。
