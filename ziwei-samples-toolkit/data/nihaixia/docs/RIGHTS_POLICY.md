# 资料采集权利政策

本项目采集倪海厦相关资料时，将资料分为四类：

## A. 已授权资料

可以保存全文、转写、切片、向量化、训练或 RAG 使用，前提是授权文件明确允许。

必填字段：

- `license_name`
- `license_document`
- `allowed_uses`
- `expires_at` 或 `perpetual`
- 授权主体与资料来源一致性

## B. 公开可索引但未授权资料

只保存 metadata，不保存正文、字幕、音视频、扫描件全文。

允许：

- 标题
- URL
- 平台
- 发布者
- 发布时间
- 媒介类型
- 主题标签
- 人工短摘要
- 少量合规短引用

不允许：

- 下载视频或音频
- 保存整段字幕
- 复制整篇文章或讲义
- 批量绕过平台限制

## C. 用户私有上传资料

只在用户授权范围内处理。不得混入公共资料库，除非用户明确授权公共使用。

## D. 禁用资料

来源不明、盗版集合、绕过付费墙、平台明确禁止下载/抓取、权利冲突严重的资料，禁止入库。

## 平台边界

YouTube、Bilibili、网盘、课程站点等视频/音频平台，默认只登记 metadata 与链接。除非获得授权或平台 API 明确允许，不下载音视频、不保存字幕全文。

## 审计规则

每条来源都必须有：

- `rights_status`
- `storage_policy`
- `collection_actions`
- `human_review_status`
- `risk_level`

任何 `rights_status=unknown` 的资料，不得进入可训练语料。
